## 「众达AI」公司官网原型（D:\通用框架\公司网站\web）代码走查 + 视觉评审

**技术栈**：Vite 6 + React 19 + @phosphor-icons/react + recharts；单页营销站（App.jsx 全站一文件 16.6KB，styles.css 20.9KB 压缩成 4 行）。
结构与区块：header 吸顶导航 → hero（hero.png 全幅背景 + 玻璃质感连接标志）→ pillars 三理念卡 → products 六能力卡 → showcase 一站式平台（内嵌 Dashboard 组件：工作台/对话中心/知识库/智能体 四个可切换 tab + recharts 面积图）→ solutions 四行业 tab（行业照片用 reference.png 精灵图裁切）→ about → contact-banner → footer。
交互：三档 `<dialog>` 弹窗（产品详情 / 交互演示 / 联系表单），联系表单只在前端生成可下载的 txt 摘要（不上传），Modal 做了 showModal + 焦点归还 + 遮罩点击关闭 + body 滚动锁。行业 tab 有完整 ARIA（tablist/tab/tabpanel + 方向键切换）。

**验证结果**：`npm run build` 通过（dist/client/index.html + dist/server/index.js + dist/.openai/hosting.json 齐全，符合 Sites 交接要求）；`npm run test:sites` 4/4 通过。JS 产物 623.57 kB / gzip 187.35 kB（超 500kB 警告）；CSS 20.94 kB / gzip 5.26 kB。

**发现的问题（按优先级）**
1. **`.hero-caption{display:none}` 是顶层规则（大括号深度 0），导致「以连接，创造价值 / CONNECTED INTELLIGENCE」在桌面端也被永久隐藏**——明显是想写进 `@media(max-width:760px)` 块（该块里还给 .hero-caption 重新定位了 bottom:43px;left:0;right:0），属于收尾时的漏写。二选一：删掉这行让文案显示（桌面端 CSS 已完整），或连 JSX 一起删。
2. **静态资源浪费严重**：`public/assets` 共 6.5MB，其中 `finance.png`(2.3M) 与 `retail.png`(2.2M) **完全没有被引用**（孤儿文件，但 build 会照抄进 dist）；`reference.png`(1.4M, 6688×3764) 被当成精灵图，用 `background-size:6688px 3764px` + 4 组硬编码 `background-position` 裁出行业缩略图 —— 为 350×255 的小图加载 1.4MB 原图。建议：删孤儿、把精灵图切成 4 张 ~600px 宽的 JPG/WebP、hero.png 转 WebP。
3. **index.html 没有 favicon**（/favicon.ico 返回 404），也无 og:image/twitter 卡片 meta；手上已有 logo.png 可直接用。
4. **`@import url('https://fonts.googleapis.com/...')` 拉 Google Fonts 的 Noto Sans SC 7 个字重**：`@import` 本身阻塞渲染；国内访问 fonts.googleapis.com 不稳定（备选 `fonts.googleapis.cn`，实测 200）。建议自托管 woff2 子集或走国内 CDN。
5. **JS 单包 623kB**：recharts 只在 Dashboard 里用到，可对 Dashboard 做 `React.lazy` + 动态 import 拆包，首屏能省一大截。
6. 文案切图小瑕疵：`.product-card h3{white-space:nowrap}` 在 6 列窄卡里对「系统集成」这类标题有溢出风险（1024/390 断点已各自重排，安全）；demo 弹窗内 `.expanded{height:440px}` 会把 recharts 的 X 轴标签裁掉半截（是刻意的"窗口被切"效果，但轴文字被腰斩略糙）。

## 视觉调性体检（科技感 / 高级感，硬数据）

在 styles.css 里数出来的用量：
- `@keyframes` **0 个**；`animation:` 声明 **1 处**（仅 reduced-motion 关停用）；`transition:` **4 处**（.primary/.secondary/.product-card/.text-link/.industry-tabs 之类）。
- `linear-gradient` / `radial-gradient` **0 处**——全站唯一渐变/光感来自 hero.png 那张位图。
- `box-shadow` 9 处，但**不透明度普遍 2.7%~6%**（`#183e7407`、`#215ba410`、`#315b8810`、`#153b6510`）；只有按钮 10%（`#1767ff19`）和弹窗 20%（`#152d5833`）有真实存在感。→ 卡片读起来是"印刷品"而非"浮在页面上"。
- `border-radius` 出现 **14 个不同值**：5/6/7/8/10/12/13/15/16/18/30px + `50%` + 两个复合值。没有圆角阶梯（如 8/12/16 三档），这是高级感的主要破绽之一。
- 字号偏小：dashboard 演示区大量 8~11px（`.dash-metrics span{font-size:8px}`、`.chart-title{font-size:8px}`、卡片正文 11px、`.card-bottom` 10px），放大看有"缩略图感"。

**结论定性**：调性偏「克制的日式/高端 B2B 企业站」，高级感靠留白+字号层级+单色克制成立（约 7.5/10）；科技感几乎全部压在 hero 位图上、页面本身贡献很少（约 6/10）——0 渐变、0 关键帧、无滚动入场、无数据纹理、无暗色反差段。

**若后续要做视觉升级，优先级**：① 统一圆角阶梯 ② 重建阴影/景深 3 档 ③ 补滚动入场（IntersectionObserver + opacity/translateY，注意 `prefers-reduced-motion`）④ hero 与行业图换 WebP/AVIF ⑤ recharts 懒加载。

**截图工具链（重要）**：沙箱里 `agent-browser` 未安装，nuphus MCP 浏览器有 SSRF 守卫（拒 127.0.0.1，需 NUPHUS_MCP_ALLOW_PRIVATE_NAV=1）。改用 `ms-playwright/chromium_headless_shell-1234/chrome-headless-shell.exe` + 自写原生 WebSocket CDP 脚本（Node 22 内置 WebSocket，零依赖）—— 已固化为技能 `local-page-screenshot`。
